# Curso de FlutterFlow

Bienvenido/a al curso de **FlutterFlow** para el ciclo de **Desarrollo de Aplicaciones Multiplataforma (DAM)**.

En este curso aprenderás a construir aplicaciones móviles y web funcionales sin escribir código, utilizando la plataforma visual FlutterFlow conectada a servicios en la nube.

---

## ¿Qué aprenderás?

- Familiarizarte con el entorno visual de FlutterFlow
- Diseñar interfaces con widgets y layouts
- Gestionar la navegación entre pantallas
- Conectar tu app a una base de datos en tiempo real
- Añadir lógica y acciones sin código
- Desplegar tu aplicación en la web y en dispositivos móviles
